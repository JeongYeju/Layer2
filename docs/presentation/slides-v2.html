꿰뚫는 척하지 않는다

검증은 정확도보다 납득도에 가깝다.
행동 신호와 개입 타이밍 연구는 설계 기반이다. 다음 검증은 사용자가 촛불을 방해가 아니라 발견으로 느끼는지, 맵을 보고 “맞아, 내가 이렇게 읽었지”라고 납득하는지에 둔다.
흔적 밑줄, 주석, 체류, 되돌아읽기처럼 실제 행동에서 출발한다.
경향 맞고 틀림보다, 어떤 방식으로 읽었는지의 패턴을 본다.
납득 검증은 정확도보다, 사용자가 자기 읽기를 이해할 수 있는지에 둔다.
