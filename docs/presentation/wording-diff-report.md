# Layer 2 발표 덱 : 워딩 before/after 분석 리포트

> **무엇** : Codex가 생성한 초기 슬라이드 덱(`slides-v2.html`, 13장)을 **before**로, 세미파이널 이후 다듬어진 현재 Figma 덱(슬라이드 표시 텍스트)을 **after**로 두고, 문구·문체가 어떻게 교정·변형됐는지 1:1로 분석한다.

## 3. 축별 심층 분석

### 축 A : 구어 설명문 → 학술 명사구 (정보 밀도·격식 상승)
발표가 다가오며 lead가 **문장에서 명사구로 압축**됐다. 가장 극적인 사례:
- Problem lead : `넓어졌는데, 가운데가 비었다.` → `수평적 확장과 깊이의 부재`
- Teaser lead : `읽은 척 말고, 글이랑 진짜 지지고 볶은 자국.` → `글이랑 지지고 볶은 흔적의 시각화`

편집 원리: 슬라이드는 *말로 보충*되므로, 표시 텍스트는 청자가 한눈에 잡는 **개념 라벨**이면 된다. 구어 뉘앙스는 스크립트로 내려가고 슬라이드는 격식·압축을 택했다. (단, Context·How 본문 같은 *서사 근거* 문장은 일부러 구어를 유지 → 축 E 참조)

### 축 B : 단정 → 가정/질문 (내러티브 훅)
클라이맥스 헤드라인이 **닫힌 평서에서 열린 조건문으로** 바뀌었다.
- Innovation : `문서가 내 흔적을 되읽는다.` → `문서가 내 흔적을 읽을 수 있다면.`

마침표 단정을 "…있다면."으로 열어, 다음 장으로 청자를 끌고 가는 *질문형 전환*을 만든다. 발표(시간축 매체)에 맞춘 수사 변형.

### 축 C : 방어적 헤지·1인칭 회고의 제거 (역설적 honesty 압축)
흔히 "정직하게 = 더 많은 단서·디스클레이머"라고 보지만, 이 덱은 **반대로** 갔다. 슬라이드 표층에서 방어 문구와 감정 회고가 **삭제**됐다.
- One sentence body : `시스템이 나를 꿰뚫는다는 뜻은 아닙니다.` **삭제**
- Validation : 헤드라인 `꿰뚫는 척하지 않는다` → `행동에서 인지를 읽는 근거` (방어 → 근거 제시)
- Future : `조금 무리했습니다. 그래도 지금, 움직입니다.` **삭제** → 객관 보드

편집 원리: 방어/겸양은 *말(스크립트)*로 전하고, **슬라이드는 자신 있게 근거를 제시**한다. 정직성은 사라진 게 아니라 References 신설·"파라미터는 휴리스틱(미보정)" 고지처럼 *검증 가능한 형태*로 재배치됐다.

### 축 D : 설명 본문 → 실제 스크린샷 (말보다 증거)
세 슬라이드에서 **설명 문단이 제품 캡처로 교체**됐다.
- Teaser : 캔버스 단어 애니메이션 → 실제 화면
- MentalMap : `…한 장의 지형으로 접었다.` 본문 + 임베딩 부주석 **삭제** → 리포트 패널 캡처
- Demo : 캡션만 남기고 화면이 주인공

"작동한다"를 *서술*하던 데서 *보여주기*로. (세미파이널 회고에서 "100 만들어도 50 전달되면 50"이라는 전달 우선주의와 정합.)

### 축 E : 보존된 코어 (무엇을 *안* 건드렸나)
가장 흥미로운 신호는 **손대지 않은 문장**이다.
- Context 전체(`종이책은 좁았지만, 깊었다.` 포함) : verbatim
- How 카드 1·3 설명 : verbatim
- Innovation 후반부, Development 리드 : 유지

즉 편집자는 **"개념과 부딪힌다=신호"라는 근거 서사**(왜 행동이 인지의 프록시인가)는 토씨 하나 안 바꿨다. 바꾼 건 *포장(표기·레이아웃·라벨)*과 *주변부*. 코어 논증의 안정성이 곧 이 프로젝트의 축.

### 축 F : 구조 확장: 여정·근거·예시의 외화(externalize)
신설/분할 슬라이드는 모두 **암묵적이던 맥락을 표면으로** 끌어올린다.
- **출발점/이후** : "원래 프로토콜 설계였다 → 경쟁사를 만났다"는 *제작 여정*을 슬라이드화
- **Examples** : 추상 주장("나를 알기")을 *표면장력/저녁에 읽으세요* 구체 장면으로
- **References + Validation 용도변경** : 주장 옆에 *문헌 근거*를 명시
- **Development 1→2 분할** : "무엇을 모았나(신호)"와 "그걸로 뭘 하나(파이프라인)"를 분리

기말 *프로젝트* 발표(과정·근거가 평가 대상)라는 성격에 맞춰, 말로만 흐르던 것을 **검증 가능한 슬라이드**로 외화한 셈.

## 4. 한국어 서술 방식(문체) 정밀 분석

> §3이 "왜 바꿨나(편집 전략)"라면, 여기는 "한국어 안에서 *어떻게* 바뀌었나"를 국어 문체론(종결·어휘·통사·양태·지시·수사) 관점으로 본다. 대상은 슬라이드 표시문(발화 대본 아님). 모든 예시는 verbatim.

### L1. 종결 양태 : 본문은 평서 '한다체' 유지, 표제는 '명사형 종결(체언 마침)'로
- 본문은 before/after 모두 문어 **한다체**(평서 종결 '-ㄴ다/-다')를 유지 : `이해가 생겼다`, `신호로 본다`, `움직이게 한다`.
- 반면 교정·신규 **표제(headline/lead)는 체언 종결**로 이동. 서술어가 탈락하고 한자어 명사로 끝맺는다 :
  - `넓어졌는데, 가운데가 비었다.`(평서) → `수평적 확장과 깊이의 부재`(체언 종결)
  - `읽은 척 말고, … 자국.` → `흔적의 시각화` · 신규 표제 `행동에서 인지를 읽는 근거` · `… 한 장으로 이해` (근거/이해로 마침)
- 효과 : 표제의 **명사구화(nominalization)** = 슬라이드를 "문장"이 아니라 "표제어"로 읽히게 한다.

### L2. 어휘 층위 : 주변 설명은 '고유어→한자어', 코어 은유는 '고유어 보존'
한국어의 격식·추상도를 좌우하는 **고유어 : 한자어 비율**에서 뚜렷한 이중 전략 :
- 주변 설명문은 **한자어 추상명사 밀도↑** : `넓어졌는데 가운데가 비었다`(전부 고유어) → `수평적·확장·부재`(한자어) · `진짜 지지고 볶은 자국` → `시각화` · `경향을 비출 뿐…` → `인지를 읽는 근거`.
- 그러나 **정서 코어 은유는 고유어 그대로 잠금** : `지지고 볶기`·`씨름`·`흔적`·`거울` 전부 고유어이며 KEPT.
- 효과 : "격식은 한자어로, 정서는 고유어로" 분리 운용 → 학술 톤과 따뜻함을 어휘 층위에서 동시 확보.

### L3. 통사 압축 : 완결문→명사구, 쉼표 나열→가운뎃점 등위
- **절→구** : 주어-서술어 완결문이 관형구+명사로 축소(L1과 연동).
- **등위 표지의 시각화** : 나열의 쉼표가 가운뎃점(·)으로 교체되어, 연결어미·조사 없이 병렬을 기호로 표시 : `밑줄, 머묾, 되돌아읽기` → `밑줄·머묾·되돌아읽기` · `하이라이트, 주석, 체류, 되돌아읽기` → `하이라이트·주석·체류·되돌아읽기`.
- 효과 : 문장 호흡이 짧아지고 등위 항목이 "어휘 묶음"으로 시각 단위화.

### L4. 서법·양태 : 단정 평서→가정/조건, 부정 양태(헤지) 소거
- **서법 전환** : 단정 평서 종결이 연결어미 '-다면'의 조건절로 열린다 : `문서가 내 흔적을 되읽는다.` → `문서가 내 흔적을 읽을 수 있다면.`
- **부정 양태 삭제** : 'X는 아니다/않는다' 식 방어 양태 제거 : `… 꿰뚫는다는 뜻은 아닙니다.`(삭제) · `꿰뚫는 척하지 않는다`(부정) → `행동에서 인지를 읽는 근거`(긍정 명사구).
- 효과 : 유보·방어 양태가 빠지고, 표제는 *단정* 또는 *열린 질문* 둘로 수렴.

### L5. 화자 현전(deixis) : 1인칭 *정서* 표지 삭제, 1인칭 *소유* 지시는 잔존
- 감정·고백의 1인칭 정서 표지가 삭제되어 비인칭 객관문으로 : `조금 무리했습니다. 그래도 지금, 움직입니다.` → (삭제) → 완료/다음 명사 보드.
- 단, **컨셉을 지탱하는 1인칭 소유 지시('나/내')는 보존** : `나를 아는 독서`·`내가 무엇을 어떻게 엮었는지`·`내 흔적`.
- 효과 : "고백하는 나"는 지우고 "주체로서의 나"는 남겨, 객관화와 컨셉을 동시 확보. (해요체 발화·겸양은 스크립트로 이양.)

### L6. 담화 부사 → 주제 표지(콜론)
- 문두 담화 부사가 빠지고 콜론(:)이 주제-설명 구조를 대신한다 : `먼저, 흔적이 보이게 했다` → `신호: 흔적을 남길 수 있게 하기`.
- 효과 : 시간 순서를 일러주던 부사('먼저,')가 사라지고 "주제어 : 풀이"라는 사전·표제식 통사로 압축.

### L7. 수사 : 시적 은유 *약화* + 대칭 대구 *신설* + 코어 은유 *보존*
- 시적 은유는 기능 서술로 하향 : `흔적이 선이 되는 순간` → `흔적을 눈에 보이게` · `내 읽기가 만든 작은 세계` → `내가 무엇을 어떻게 엮었는지, 한 장으로 이해`.
- 반면 **대구(對句)는 신설**되어 수사가 한 점에 집중 : `사람이 문서를 읽는다 에서, 문서가 사람을 읽는다 로.`(주술 교차의 대칭).
- 코어 은유(`지지고 볶기`·`씨름`·`거울`)는 불변.
- 효과 : 은유를 덜어내되 클라이맥스 한 곳에 몰아, 수사의 낭비 없이 인상점을 만든다.

### L8. 시제·상 : 회상 과거 안정(거의 불변)
- Context의 회상 과거('생겼다/넘겼다')처럼 시제·상 운용은 before/after에서 거의 그대로. 변화가 **종결·어휘·통사**에 집중되고 시제 축은 건드리지 않은 점이 특징 → 서사 시간 구조는 안정.

**문체론 요약** : 한국어 층위 변화는 *(i) 표제의 명사형 종결화, (ii) 주변부 한자어화 ↔ 코어 고유어 보존, (iii) 절→구·쉼표→가운뎃점 통사 압축, (iv) 단정/가정 양태로의 수렴과 헤지 소거, (v) 정서 1인칭 삭제·소유 1인칭 보존*. 한 줄로 : **"표제는 명사·한자·단정으로 굳히고, 정서·은유·1인칭 소유는 고유어로 남겼다."**

## 5. 삭제 인벤토리 (before에 있었으나 after에서 사라진 것)

"무엇을 *고쳤나*"만큼 "무엇을 *지웠나*"가 신호가 크다. DROPPED + 흡수 항목을 성격별로.

- **A. 자기-방어/헤지 삭제** : `시스템이 나를 꿰뚫는다는 뜻은 아닙니다.`(One sentence 디스클레이머) · Validation 표제 `꿰뚫는 척하지 않는다`(부정 자기규정) · 출발점/이후의 정직 포지셔닝 밴드(AI가 넣은 걸 사용자가 압축·삭제).
- **B. 1인칭 정서·회고 삭제** : Future `조금 무리했습니다. 그래도 지금, 움직입니다.`(감정 고백) → 객관 보드.
- **C. 정체성 장식 삭제(일부는 *이동*)** : Title 트라이어드 `Wrestle · Trace · Mirror`(+한글). 단 **ColdOpen 다크 푸터엔 잔존** → 완전 삭제가 아니라 *위치 이동*. · How 중앙 헤드라인 `씨름하고, 남기고, 비춘다`.
- **D. 기술 부주석 삭제** : MentalMap `동의어와 의역까지 잇는 의미 연결 : Gemini 임베딩 코사인` · Validation 3척도(흔적/경향/납득).
- **E. 설명문이 스크린샷으로 흡수(텍스트 소멸)** : MentalMap 본문 · Teaser 캔버스 단어 · Problem 칩.

**삭제의 의미** : 사라진 것의 대부분이 *방어·정서·장식*이다. 반면 *근거(이론)는 삭제가 아니라 전용*(Validation→근거 카드)·*신설*(References)로 자리만 옮겼다. 즉 "덜 말하기"가 곧 "덜 정직하기"는 아니며, 정직성은 검증 가능한 형태로 외화됐다.

## 6. 서사 흐름 변화 (최종 발표 순서 s01~s23 vs Codex 13장)

- **Codex(before)** : Title→One→Teaser→Context→Problem→Innovation→How→Dev→Demo→Map→Validation→Conclusion→Future. 단선 DIE.
- **현재(after)** : Title→**[ColdOpen 다크]**→One→Teaser→Context→Problem→Innovation→How→**[Trace 다크]**→Examples→Dev1→Dev2→**출발점**→**이후**→Demo→Map→[Demo vid]→Validation→Conclusion→**[Conclusion 다크]**→Future→**References**→[Title-Layer3].

구조 변화 3가지 :
1. **다크 변형 3장이 구두점처럼 삽입**(콜드오픈·Trace·결론) → 흰 본문의 리듬을 끊어 강조점 형성.
2. **여정 슬라이드(출발점·이후)가 본론 중반(How~Demo 사이)에 삽입** → "원래 신호 설계였다 → 경쟁사" 회고가 초반 훅을 건드리지 않고 중간에. (단, Dev1·Dev2·출발점·이후가 연달아 와 **중반 정보 밀도 과적**은 리스크.)
3. **근거·클로징이 꼬리에 추가**(References·Title-Layer3).

효과 : 단선 DIE가 *흰/다크 교차 + 여정 삽입 + 근거 꼬리*의 다층 시퀀스로 재편됐다.

## 8. 순효과 (요약)

세미파이널 → 현재의 워딩 변화는 한마디로 **"코어 서사는 잠그고, 표층은 규범화·압축하며, 맥락(여정·근거·예시)은 외화"**다. 표기는 올캡스 아이브로·가운뎃점 구분자로 일관됐고(규범화), lead는 문장에서 명사구로 격식이 올라갔으며(축 A), 클라이맥스는 질문형으로 열렸고(축 B), 방어적 헤지와 1인칭 회고는 표층에서 빠져 검증 가능한 근거(References·휴리스틱 고지)로 자리를 옮겼다(축 C). 동시에 "왜 행동이 인지의 신호인가"라는 근거 문장과 핵심 은유(지지고 볶기)는 그대로 보존됐다(축 E). 지운 것은 대개 방어·정서·장식이었고 근거는 자리만 옮겼으며(§5), 흐름은 흰/다크 교차의 다층 시퀀스로 재편됐다(§6). 편집 주체로 보면 **AI 리라이트는 확장·신설, 사용자 손질은 절제·복원**으로 갈렸다(§7). 결과적으로 덱은 *덜 변명하고, 더 보여주고, 더 학술적으로* 변했다.
