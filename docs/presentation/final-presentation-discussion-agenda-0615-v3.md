# Layer 2 최종 발표 의논 아젠다 v3

> 목적: 최종 발표 구조를 바로 확정하지 않고, 의논해야 할 쟁점을 빠짐없이 추적한다.
> 운영 원칙: 기존 생성 문서는 수정하지 않는다. 합의가 쌓이면 새 수정본 문서를 별도로 만든다.
> v3 변경: 기능 파트 구조를 `읽기 전 / 중 / 후`에서 **읽기 시작 / 읽기 중 / 읽기 후 / 다음 읽기 전** 4단 구조로 락.

---

## 락된 결정

### 1. 컨셉 프레임

- 축약형: **씨름 / 흔적 / 거울**
- 발표용 쉬운 풀이: **지지고 볶기 / 흔적 남기기 / 나를 비추기**

의미:

- `씨름 / 흔적 / 거울`은 Layer 2가 읽기를 바라보는 관점이자 컨셉 프레임이다.
- 발표에서는 더 쉽게 `지지고 볶기 / 흔적 남기기 / 나를 비추기`로 풀어 말한다.
- 기능 구조와 같은 레벨에 두지 않는다.
- `세계관`이라는 워딩은 임시 라벨로만 사용하고, 발표/문서에서는 `관점`, `컨셉 프레임`, `문제의식/제안`을 우선 사용한다.

### 2. 기능 파트의 상위 구조는 4단 구조

락된 구조:

> **읽기 시작 -> 읽기 중 -> 읽기 후 -> 다음 읽기 전**

이유:

- 기존 `읽기 전 / 중 / 후`는 원의도상 맞지만, 발표에서는 `읽기 전`이 두 의미로 섞인다.
- 첫 번째 `전`: 아직 흔적이 없는 상태에서 글을 여는 진입.
- 두 번째 `전`: 이전 독서의 흔적이 다음 독서의 맥락이 되는 지점.
- 우리가 강조하고 싶은 비전은 두 번째 `전`이다.
- 따라서 `읽기 시작`과 `다음 읽기 전`을 분리한다.

| 기능 단계 | 정확한 의미 | 예시/기능 |
|---|---|---|
| 읽기 시작 | 무거운 글을 Layer 2 안으로 가져와 읽기 시작하는 진입 | 웹 글/PDF/마크다운을 뷰어로 가져오기, 소스 로딩 |
| 읽기 중 | 글과 씨름하며 흔적이 생성되고 개입이 일어나는 지점 | 신호 수집, 마찰 해석, 촛불 개입, 티키타카, 뷰어/보드 전환 |
| 읽기 후 | 흔적이 노트/맵/리포트로 가공되는 지점 | Mental Model Map, 독서 후 티키타카, 다회독 리포트, 재독 Diff |
| 다음 읽기 전 | 읽기 후 산출물이 다음 읽기의 맥락이 되는 지점 | "이 논문, 저녁에 읽으세요", 이전 세션 복귀, 지난번 오래 붙잡은 구간 |

핵심:

> `읽기 시작`은 제품 진입이고, `다음 읽기 전`은 Layer 2의 비전이다.
> `읽기 후` 산출물이 다음 독서의 `읽기 전` 맥락으로 돌아온다.

### 3. 확장프로그램은 본편에서 크게 다루지 않는다

- 기능 파트가 과밀해지므로 확장프로그램 자체 설명은 본편에서 뺀다.
- `읽기 시작`에서 한 문장 정도로만 처리한다.

발표 멘트 후보:

> 웹 글, PDF, 마크다운처럼 흩어진 글을 Layer 2 뷰어 안으로 가져와 읽기 시작합니다.

자세한 구조는 Q&A Appendix의 `무엇을 만들었나` 장으로 보낸다.
