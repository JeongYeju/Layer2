## 락된 결정

### 1. 세계관 프레임

- 축약형: **씨름 / 흔적 / 거울**
- 발표용 쉬운 풀이: **지지고 볶기 / 흔적 남기기 / 나를 비추기**

의미:

- `씨름 / 흔적 / 거울`은 Layer 2의 철학/개념 프레임이다.
- 발표에서는 더 쉽게 `지지고 볶기 / 흔적 남기기 / 나를 비추기`로 풀어 말한다.
- 기능 구조와 같은 레벨에 두지 않는다.

### 2. 기능 파트의 상위 구조는 `읽기 전 / 읽기 중 / 읽기 후`

이유:

- `신호 분석 / 촛불 / 거울`은 시스템 기능 구조다.
- `씨름 / 흔적 / 거울`과 단어가 겹치고 스코프가 달라, 상위 구조로 쓰면 혼동이 생긴다.
- `읽기 전 / 읽기 중 / 읽기 후`는 독자가 경험하는 시간 구조라 더 직관적이다.
- 단, 선형 순서가 아니라 `전 -> 중 -> 후 -> 다시 전`의 순환 구조다.

### 3. 0602/원 회의록 기준 `전 / 중 / 후` 원의도

| 시간 구조 | 정확한 의미 | 예시 |
|---|---|---|
| 읽기 전 | 이전 독서 후 남은 흔적이 다음 독서의 맥락이 되는 지점 | "이 논문, 저녁에 읽으세요", 이전 세션 복귀, 지난번 오래 붙잡은 구간 |
| 읽기 중 | 글과 씨름하며 흔적이 생성되고 개입이 일어나는 지점 | 신호 수집, 마찰 해석, 촛불 개입, 티키타카, 뷰어/보드 전환 |
| 읽기 후 | 흔적이 노트/맵/리포트로 가공되어 다음 읽기를 바꾸는 지점 | Mental Model Map, 독서 후 티키타카, 다회독 리포트, 재독 Diff |

핵심:

> `읽기 전`은 단순 추천/큐레이션이 아니다.
> `읽기 후` 산출물이 다음 독서의 `읽기 전` 맥락으로 돌아오는 지점이다.

### B. 세계관과 기능 프레임의 연결 문장

상태: 의논 필요.

현재 가설:

> Layer 2의 세계관은 씨름, 흔적, 거울입니다.
> 쉽게 말하면 글과 지지고 볶고, 그 과정의 흔적을 남기고, 그 흔적으로 나를 비추는 독서입니다.
> 이제 이 세계관이 실제 독서 시간 안에서는 읽기 전, 읽기 중, 읽기 후로 어떻게 작동하는지 보겠습니다.

질문:

- 이 문장을 그대로 사용할지.
- `나를 비추기`와 `나를 아는 독서`가 중복되므로 더 좋은 표현이 있는지.

### C. 읽기 전

상태: 다음 의논 대상.

정의:

- 이전 독서의 흔적이 다음 독서의 맥락이 되는 지점.
- 예시로 "이 논문, 저녁에 읽으세요"가 포함된다.
- 단, 추천 기능 자체가 핵심이 아니라 `후 -> 다음 전` 순환의 증거다.

질문:

- `읽기 전`의 본편 예시는 `저녁에 읽으세요` 하나로 충분한가.
- 구현/비전 경계를 어떻게 말할지.
- 첫 발표 오프닝의 `저녁에 읽으세요`를 여기서 회수할지.

### D. 읽기 중

상태: 의논 필요.

들어갈 기능 후보:

- 신호 수집: 밑줄, 주석, 체류, 되돌아읽기, 동그라미, 스크롤.
- 해석: 문서 내 상대 마찰, ICAP, productive/extraneous 구분.
- 개입: 촛불, 티키타카.
- 뷰 전환: 읽기 뷰, 보드 뷰.

질문:

- 본편에서 반드시 보여줄 읽기 중 기능은 무엇인가.
- 촛불을 주연으로 둘지, 보드 전환까지 같은 무게로 둘지.

### E. 읽기 후

상태: 의논 필요.

들어갈 기능 후보:

- Mental Model Map.
- 독서 후 이해 점검 대화.
- 다중 세션 리포트.
- 재독 Diff / 다회독 거울.

질문:

- 본편에서 `후`를 어디까지 보여줄지.
- `후 -> 다음 전` 순환을 한 장에서 보여줄지, Future에서 보여줄지.

### F. 마지막 프레이밍

상태: 의논 필요.

사용자 희망 방향:

> AI가 읽을 수 없던 것을 읽게 됐을 때 어떤 가능성이 생기는가?
> 그리고 디자이너로서 무엇을 읽게 해야 하는가?

질문:

- 이 질문을 마지막 한 장의 문장으로 둘지, Future 이전의 비전 장으로 둘지.
- `AI가 텍스트를 읽는다`가 아니라 `AI가 독서의 흔적을 읽는다`로 정확히 고정할지.
- 디자이너의 역할을 `무엇을 자동화할까`가 아니라 `무엇을 읽을 가치 있는 신호로 만들까`로 말할지.
