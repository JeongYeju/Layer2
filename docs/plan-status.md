## 1. 제품 정의 (기획안)

- **무엇** — "나를 아는 독서"를 돕는 디지털 리더. 텍스트 이해(내재화) + 독서 습관/패턴 이해(메타인지).
- **읽기 인터랙션의 변화** — 종이책(흔적은 남지만 독자만 앎) → 디지털(흔적은 사라짐) → **Layer 2(흔적을 남기게 하고, 그걸 읽고 움직인다)**.
- **움직임 1 (텍스트를 알기)** — 표면장력 개념을 왔다갔다 하면, 글이 눈치채고 적극적으로 설명.
- **움직임 2 (나를 알기)** — 저녁에 이해가 잘 되는 사람에게, 저녁에 읽으라고 말해줌.
- **페르소나** — ① 더 깊이 이해(내재화) ② 자신의 독서 패턴 인지(메타인지) ③ 독서 중·후 AI 인터랙션 환영.

## 4. 내재화(Internalization) 인터랙션 — 아이디어 풀

> 근거: 인출 연습(retrieval practice)·자기설명(self-explanation)·정교화(elaboration)가
> 이해의 장기 내재화에 가장 효과적이라는 학습과학 합의. 모두 *흔적/세션 데이터를 재사용*하므로 추가 수집 0.

- **A. 자기설명 프롬프트** — 마찰 높은 단락 옆에 "이 부분, 한 문장으로 다시 써보기" 인라인 입력. (비용 낮음)
- **B. 인출 회상 카드** — 독서 후, 내가 **밑줄 친 문장**을 빈칸으로 만들어 채우게(능동 인출). (비용 중)
- **C. 내 말 요약 초안** — 세션 끝에 주석+하이라이트를 모아 LLM이 "요약 초안"을 만들고, 독자가 직접 고치게(편집이 곧 정교화). (비용 중, interpret 재사용)
- **D. 재독 디프(diff)** — 같은 글 재독 시 지난 마찰/주석을 겹쳐 "전엔 여기 막혔는데 지금은?" 비교. (비용 중, DB 있으면 강력)
- **E. 간격 반복 회상** — 며칠 뒤 핵심을 한 번 더 묻기. (DB 필요 → 메타인지 '할 것'과 묶임)

→ 추천 다음 한 입: **A(자기설명)** 또는 **C(내 말 요약 초안)** — 비용 대비 내재화 효과가 크고 기존 파이프라인 재사용.
